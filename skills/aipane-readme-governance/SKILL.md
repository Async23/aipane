# README 治理契约

## 1. 信息归位判据

将 README 作为项目或目录的**稳定入口**，按变动频率与权威归属分配内容：

- **留在 README**：定位、适用边界、核心能力概览、推荐阅读顺序、子目录职责、稳定的安装/运行入口，以及指向各类细则唯一事实来源（Single Source of Truth）的链接。
- **下沉到专项文档**：完整实现细则、逐字段接口契约、配置全表与长篇架构说明（README 仅留一句职责摘要与链接）。
- **交回 Issue 或 Git 历史**：易变的运行状态、阶段性联调记录、临时排障日志、未闭环待办与仅对单次重构有意义的变更流水账。

## 2. 防丢失硬红线

- **下沉而非丢弃**：删减 README 中尚无专项文档承接的唯一有效信息前，必须先将其迁入对应专项文档并核验相对链接可达；**严禁在缺乏权威落脚点时直接删掉唯一信息源**。

## 3. 完成态验收标准

删改完成后核对 README：随日常迭代频繁变动的实现细节均已归位到对应权威源，所有站内链接可达，新读者能在 1 分钟内看清项目定位、上手入口与下一步应读的文档。
